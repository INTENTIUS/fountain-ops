## Five minutes, most of it pulling images

```bash
just doctor        # what this needs, and how to install what is missing
npm install
just up            # cluster, secret, build, apply, wait, prove it serves
```

Then register at `localhost:4000/auth/register`, run `just verify-email you@example.com`,
and sign in. See [First login](/fountain-ops/getting-started/first-login/) for why
that second step is not optional.

## What you drive it with

`just` targets. You do not need to know chant to use this, and no resource file
reads `process.env`: every input is a declared build parameter, so the same
parameters produce the same resources.

```bash
just status       # everything in the namespace
just logs         # the app, following
just preview kubernetes ha         # see another target without applying anything
just down         # remove everything it created, and nothing it did not
```
