## Five minutes, most of it pulling images

```bash
just doctor        # what this needs, and how to install what is missing
npm install
just up            # cluster, secret, build, apply, wait, prove it serves
```

Then register at `localhost:4000/auth/register` and sign in — your account
self-verifies, and the instance's first account is
[the admin](/fountain-ops/getting-started/stand-it-up/#first-login).

## What you drive it with

`just` targets, and nothing else. The manifests are compiled from TypeScript
by [chant](https://intentius.io/chant), but every command you need is a `just`
target — you can deploy, operate and tear this down without learning what
chant is.

```bash
just status       # everything in the namespace
just logs         # the app, following
just preview kubernetes ha         # see another shape without applying anything
just down         # remove everything it created, and nothing it did not
```
